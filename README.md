# BioGO
A Website made with Go, HTML, and CSS for [goship](https://goship.hackclub.com/)
- It's a website themed around the biology of animals.
- It contains information such as, diet, size, group, and more.
- It also has a graph that compares different animal top speeds.
- This is my first time coding in Go.
